Git

  • git init - расшифровывается как "initialize", что переводится как "инициализировать". Создаёт новый Git-репозиторий в текущей папке.
  • git add - расшифровывается как "add", что переводится как "добавить". Начинает отслеживать изменения в файле (добавляет в staged-область).
  • git commit - расшифровывается как "commit", что переводится как "зафиксировать". Сохраняет добавленные изменения в истории репозитория.
  • git push - расшифровывается как "push", что переводится как "отправить". Загружает локальные коммиты в удалённый репозиторий.
  • git pull - расшифровывается как "pull", что переводится как "вытянуть". Скачивает свежие изменения из удалённого репозитория.
